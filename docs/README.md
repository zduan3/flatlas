## 文档维护规则

- 用户可通过根 README 完成正常使用；使用说明增长时再拆出专用使用指南，并从 README 链接。
- 0.1 基线仅用于勘误，不再承载新功能；0.2 的变更写入 `0.2/` 并在实现时更新其验收标准。
- 当前行为、冻结基线与未来提案必须分开记录；未来内容不得写成当前功能。
- 保持文件路径稳定；需要迁移时，先更新本导航和所有入站链接，再执行移动。
