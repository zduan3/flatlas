## 文档维护规则

- 用户可通过根 README 完成正常使用；使用说明增长时再拆出专用使用指南，并从 README 链接。
- 当前行为、设计约束与未来提案必须分开记录；未来内容不得写成当前功能。
- 新增或调整功能时，同时更新适用的开发契约、实现记录、使用说明和测试。
- 保持文件路径稳定；需要迁移时，先更新本导航和所有入站链接，再执行移动。
